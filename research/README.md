# Research

## Purpose

Literature notes, experiment writeups, and research memos that are not executable production code.

## Inputs

Analyst judgment, citations, and links to notebooks or model versions.

## Outputs

Markdown (or similar) documents describing hypotheses, results, and next steps.

## Dependencies

None required; may reference `docs/` and `notebooks/`.

## Assumptions

Nothing here is deployment-ready until promoted into modules with tests and backtests.

## Limitations

Narrative documents can lag code; treat module READMEs and model versions as source of truth for shipped logic.

## Validation methodology

Peer review; promotion checklist in `docs/VALIDATION.md`.
